# OPERACIÓN: CUMPLEAÑOS.EXE — v0.5

Один гость, 7 уровней, Windows XP + Ministerio del Descontrol.

## Запуск

Откройте `index.html` в браузере. Для надёжности можно запустить `python3 -m http.server 8080` в папке проекта и открыть `http://localhost:8080`.

При первом открытии появится интерактивная заставка Windows XP. Нажатие на «INICIAR WINDOWS» воспроизведёт короткую синтезированную мелодию (разрешённую браузером после клика), затем загрузится рабочий стол. В центре находится `CUMPLEAÑOS.exe` — нажмите, чтобы начать прохождение.

## Актуальные сведения

- 14 ноября 2026 года; время сбора **10:00**, НЕ вылета.
- **Aeropuerto Josep Tarradellas Barcelona-El Prat (BCN)**. Терминал не указан — требуется отдельное уточнение.
- Необходимые вещи: документ, зарядка, очки, зубная щётка, вайб, купальник, Кова Капы на дорожку.
- Назначение ни в каком файле не указано.

## Интерактивные детали

- «Пуск», «Мой компьютер», «Корзина», «TOP SECRET», а также кнопки сворачивания окна вызывают мемный BSOD с возможностью вернуться.
- «Дело №6969» открывает живое досье с раскрывающимися сведениями.
- Дон Пако издаёт короткое «эх» при клике (звук синтезируется в Web Audio). Кнопка «Звук» управляет дополнительными звуками; реакция Пако звучит при непосредственном нажатии на него.
- Выбранные предметы падают в нарисованный чемодан; предмет можно удалить повторным нажатием.
- Финальный билет можно сохранить через системный диалог печати / Save as PDF.
- Прогресс сохраняется локально под ключом `cumple-exe-v5`. Изменения контента не сбрасывают старые ключи.

## Развёртывание

Сайт статический: подойдёт GitHub Pages, Netlify или Vercel. Папку можно загрузить как есть; внешние зависимости только необязательные Google Fonts. Конфигурация находится в `event-config.js` (содержит текущие сведения о встрече). Перед финальной публикацией переименуйте этот файл в `event-config.js` и замените подключение в `index.html`. Не публикуйте дополнительные тестовые конфигурации. Важно: данные статического сайта видны через исходный код; скрываемым остаётся только фактическое направление, которого там нет.

## Обновления v0.5
- «Пройти заново» теперь очищает прохождение и возвращает к заставке Windows XP с кнопкой INICIAR WINDOWS. При обычном обновлении страницы прогресс сохраняется.
- Don Paco может неожиданно «съесть» курсор на 10 секунд после нескольких нажатий на него. Все клики на время мини-сценки заблокированы, через 10 секунд управление автоматически восстанавливается. На сенсорных устройствах это визуальная шутка.
- В финальном билете и чемодане название «Кова Капы на дорожку» одинаковое.
- Для теста повторного прохождения завершите квест, нажмите «Пройти заново», затем «INICIAR WINDOWS» и откройте файл по центру стола.


## v0.6
- Неверные ответы на CAPTCHA, экзамене, табло и таможне: Don Paco забирает курсор на 10 секунд.
- При выборе нескольких вариантов/предметов сохраняется положение страницы, нет полной перерисовки.
- После каждого завершённого уровня: загрузка сайта министерства → ERROR 404 → восстановление → следующий этап.
- Звук неверного ответа воспроизводится, когда включён звук в панели Пако (браузеры требуют разрешения на звук через действие пользователя).


## v0.7 обновления
- Don Paco съедает курсор после **двух подряд** неправильных ответов, а не при каждой ошибке. Шесть разных сценок и реплик; каждое успешное решение обнуляет серию ошибок.
- Между этапами и вопросами экзамена: 3.5 секунды заставки Windows XP с песочными часами, без постоянного 404.
- После успешной сборки чемодана: 5-секундный красный экран «LO SIENTO, ВСЁ ЕБНУЛОСЬ. Espera» с обратным отсчётом.
- В финале: синтезированные звуки хлопушек вместе с конфетти (звук включается после нажатия кнопки запуска XP, может быть выключен у Don Paco).
- Повторный запуск сбрасывает прогресс и возвращает заставку.
